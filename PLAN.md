# BuyerAnons - Сервис мониторинга скидок

## Обзор
Сервис для автоматического сбора акционных предложений из иностранных интернет-магазинов с отправкой результатов в Viber.

## Целевые магазины
- ASDA (direct.asda.com)
- Zara, H&M, Mango
- Amazon, eBay
- Возможность добавления новых

## Сценарий использования

1. Пользователь отправляет боту команду:
   ```
   /scan https://direct.asda.com/george/men/sale/ --sizes M,L,42,43 --top 15
   ```
2. Бот отвечает "Сканирую ASDA..."
3. Через 30-60 сек бот отправляет карточки товаров

## Параметры запроса

| Параметр | Описание | Пример |
|----------|----------|--------|
| `url` | URL страницы со скидками | `https://direct.asda.com/george/sale/` |
| `--sizes` | Размеры одежды/обуви | `M,L,XL,42,43` |
| `--top` | Кол-во товаров (по умолчанию 10) | `15` |
| `--min-discount` | Минимальная скидка % | `50` |

## Инфраструктура

### Локальная разработка
- Docker контейнер с Python 3.11 + Playwright
- Volumes для hot-reload кода
- Локальный .env файл

### Продакшен (AWS Ubuntu 22)
- Docker контейнер
- GitHub Actions для CI/CD
- Systemd для управления

## API ключи (нужно получить)

1. **DeepL API**: https://www.deepl.com/pro-api (бесплатно 500k символов/месяц)
2. **bit.ly**: https://bitly.com/a/oauth_apps
3. **Viber Bot**: https://partners.viber.com/
